<inputs>
歌曲：《词不达意》林忆莲 · 词 小寒 · 曲 Peter Svensson · 编曲 刘志远（2006《呼吸》），4:26.5
原材料：source/song.mp3、source/lyrics.lrc（用户提供，不入库）；source/analysis.md（歌词与意境分析）
想让观众记住的一句话：最难翻译的不是「我爱你」，是自己。
规格：266.5 秒，1920×1080，30fps；音轨直接用原曲（只做防削顶处理）
主角：「我」= 暖黄像素小家伙 #F0AA5A（14×11 像素网格，参考 Claude Code 像素小人造型，非官方形象）；
      「你」= 无五官的冷蓝光滑人形 #7FA7CF。像素 vs 矢量：两人连画法都不同，天生需要翻译。
配色：夜 #141C24 / 雾灰蓝 / 纸白 #EDEBE6；唯一的红 #D7263D 只给「爱」和最后那颗像素。
字体：思源宋体 Noto Serif SC（玻璃上的字、字雨），本地加载。
歌词：不做整句字幕。只让小家伙在玻璃上写出零星的字（我 / 爱 / 你 / 快乐 / 恐惧 / 猜疑 / 词不达意）。
</inputs>

<direction>
诗意的来源：留白、慢、重复的母题（雨 / 雾 / 玻璃 / 字 / 倒影），而不是煽情。
母题的变形贯穿全片：雨 → 玻璃上的水痕 → 城市的雨 → 落下的字 → 字落进水面 → 倒影 → 又回到玻璃上的雾。
「你」从头到尾不说话、几乎不回头；只有结尾一次面向窗。
两次副歌是同样的失败：第二次更近、更满。间奏 30 秒没有字，只有字碎掉的过程。
结尾不给答案：手和爪隔着玻璃对齐，差几毫米，雾升起，灯熄。
镜头：每一幕都有缓慢推近；城市一幕是横向跟拍，副歌 2 时停下；倒影一幕镜头最近。
禁止：哭泣特写、暴雨闪电等激烈表达；居中整句歌词字幕；深色背景 + 居中大字 + 淡入淡出的默认 MV；角色动作匀速滑动。
</direction>

<structure>
时间轴以歌词时间戳为准（感觉速度约 63 BPM，一小节约 3.8s）。

第一幕 · 窗（0:00–1:48）
- 0:00–0:13 前奏：黑场里慢慢浮出虚化的雨夜街灯与起雾的窗；6.0s 窗台小灯亮起，9.9s 小家伙从趴着站起；2–12s 左下角浮现「词不达意 · 林忆莲」。
- 0:13–0:43 主歌1「立志」：它在雾上一笔一笔写「我」「爱」「你」，每个字写完就被雾慢慢盖回去；
  28.5s 起写下零散的「快乐」「恐惧」「猜疑」。窗外，你两次撑着冷蓝的影子走过。
- 0:43–1:15 预副歌「玻璃」：你在窗外停下，站在玻璃右侧。小家伙走过去，爪按在玻璃上，离你几毫米；它的呼吸在玻璃上化开一小团又被雾吞回。
- 1:15–1:40 副歌1「失败」：它写下大大的「我爱你」；雾漫回时，三个字一笔一笔变成形近字（爱→受→叆→暧），最后流成水痕。95s 你走进雨里。
- 1:40–1:48 呼吸：小家伙也走出画面，窗台只剩灯；渐暗。

第二幕 · 城（1:48–2:46）
- 1:48–2:19 主歌2「盲点」：横向跟拍。灰色人群里，冷蓝的你往前走，虚线视野锥朝前；小家伙寸步不离走在锥的背后。
  季节轮转，每季约 7.6s：雨 → 晴 → 落叶 → 雪。
- 2:19–2:45 副歌2「重复」：跟拍停下，你停在路口。小家伙一次次跳起来喊，像素对话框里的字一个个变成形近字、问号、省略号，然后碎成像素。2:30 你继续往前，镜头重新跟上。

第三幕 · 字雨（2:46–3:15，间奏，没有歌词）
- 雨丝一根根变成落下的字；人群一个个淡去，你也走远消失；夜色褪成纸白，楼群化掉。
- 字落地碎成像素。3:10 起所有落下的字慢慢停在半空。

第四幕 · 倒影（3:15–3:56）
- 3:15.7 终段副歌起：悬停的字一齐落进地面——地面变成水面，一圈圈涟漪；水面静下来，映出小家伙的倒影。
- 3:38.9「先看明白我自己」：小家伙低头看；倒影先抬起了爪，一秒后它才跟着抬起——它第一次看见自己。
- 3:48.1「翻译成一句我爱你」：它胸口亮起一颗红色像素，慢慢飘出来，悬在它面前，向右飘去。

尾声 · 窗（3:56–4:26.5）
- 3:54–3:57 白色世界溶回雨夜的窗。这一次你站在窗外，面向这扇窗。
- 红色像素飘到玻璃前，停住，过不去。小家伙抬爪贴上玻璃；你也抬起手，掌心和爪隔着玻璃对齐，差几毫米。
- 4:03.9「却词不达意」：雾从下往上漫起；4:08.7 小家伙在最后一小块清楚的玻璃上写下「词不达意」，雾盖上。
- 4:18 灯熄；4:22 起黑场，红色像素最后熄灭。
</structure>
